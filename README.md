# Nexus AI CRM

A premium, AI-ready customer relationship management workspace for growing businesses.

## Current starter
- Responsive CRM overview dashboard
- Premium light and dark themes
- Revenue and lead-source visualizations
- Recent leads table with live search
- Add-lead interaction (local demo state)
- Responsive sidebar and mobile layout

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Tech
- Next.js App Router
- React + TypeScript
- Lucide icons
- Custom responsive CSS

## Roadmap
1. Authentication and organization setup
2. Persistent CRM database and role-based access
3. Leads, contacts, companies, deals, tasks and activities
4. AI assistant, lead scoring and follow-up generation
5. WhatsApp, email and voice integrations
6. Reports, forecasting and workflow automation

> Demo note: the current dashboard uses sample data in browser state. No production database, authentication, AI provider, or messaging integration is connected yet.
